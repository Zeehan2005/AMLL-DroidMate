# 2026-09-18 工作日志

## 字体导入 Picker  兼容性修复
- `ComponentSettings.kt`：导入字体 launcher 启动时 MIME 由 `font/*` 改为 `*/*`（部分设备可能不支持 `font/*`，会导致系统文件 Picker 无法打开 / 过滤后无文件可选）。
- 在 `importFontToInternalStorage` 落盘前按扩展名（ttf/otf/woff/woff2/ttc）严格校验，非字体文件抛 IOException，由 UI 的 try/catch 显示"导入失败"。
- 背景：对照 OPPO 官方[《文件 Picker 适配指南》](https://open.oppomobile.com/documentation/page/info?id=13711) 第六节"常用筛选类型"清单，其中无 `font/*`。
- 注：本次仅做核心修复（方向 1），未改 `AndroidManifest.xml` 的 `<queries>`（OPPO 建议补 OPEN_DOCUMENT+OPENABLE+*/* 一项，暂未实施）。
