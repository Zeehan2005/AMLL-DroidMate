# 2026-09-12

## 歌词组件：新增字重与字体大小调节

为歌词组件（AMLLLyricsView）新增「字重」与「字体大小」设置项。

### 关键架构事实（重要，避免返工）
- 核心（@applemusic-like-lyrics）通过 `--amll-lp-font-size` 消费字号；`--amll-lp-font-size-preset`（由 `window.setLyricSizePreset` 设置）在**当前版本核心里未被消费**，旧的字号预设机制实际无效。
- 字重完全无现成机制，需新增 `--amll-lp-font-weight`。
- 应用侧 `app/src/main/assets/amll/styles.css` 的 `.amll-lyric-player` 会**本地定义** `--amll-lp-font-size`，会遮蔽根级变量；因此字号必须经由中间变量 `--amll-user-font-size` 中转（styles.css 改为 `--amll-lp-font-size: var(--amll-user-font-size, <默认>)`）。
- 通过 `document.documentElement.style.setProperty(...)` 直接注入 CSS 变量即可生效，**无需改动压缩后的 amll.bundle.js**。

### 改动文件
- `app/.../global/AMLLSettings.kt`：新增 `getAmllFontWeight/setAmllFontWeight`、`getAmllLyricFontSize/setAmllLyricFontSize`（size<=0 清除=自适应）；常量 `KEY_AMLL_LYRIC_FONT_SIZE`（原 `KEY_AMLL_LYRIC_SIZE_PRESET` 改名）、`DEFAULT_AMLL_FONT_WEIGHT=400`、`DEFAULT_AMLL_LYRIC_FONT_SIZE=28`；reset 一并清除。
- `app/.../components/AMLLLyricsView.kt`：update 内注入 `--amll-lp-font-weight` / `--amll-user-font-size`；onPageStarted 重置去重标记以便重载后重应用。
- `app/.../assets/amll/styles.css`：`.amll-lyric-player` 增加 `--amll-user-font-size` 中转与 `font-weight: var(--amll-lp-font-weight, 400)`。
- `app/.../ui/settings/ComponentSettings.kt`：字体设置区新增字重滑块(100-900)与字号滑块(12-48px，带「自适应默认」开关)；还原按钮同步重置。

### 验证
- `java -jar gradle/wrapper/gradle-wrapper.jar :app:compileDebugKotlin --offline` 通过（沙箱里 gradlew 脚本缺 uname/sed，需直跑 jar）。

## 修复 AAR 元数据告警（compileSdk 37.1）

build 报 3 条 AAR 元数据告警，根因是 `androidx.compose.ui:ui:latest.release` 被解析成 **1.13.0-alpha03**（预览版，要求 compileSdk ≥ 37.1），而本地只有 android-37.0。

### 修复方式（选 BOM 稳定版，免装 preview 平台）
- `app/build.gradle.kts`：Compose BOM 固定为稳定版 `androidx.compose:compose-bom:2026.09.00`（映射 ui→1.12.1，无 minCompileSdk 限制）；去掉所有 `androidx.compose.*` 依赖上的显式 `:latest.release`，改由 BOM 统一接管版本。
- 保留 `compileSdk = 37`（稳定 android-37.0），无需升级到 preview SDK，也无需安装 android-37.1 平台。
- 经验：Compose 依赖**不要**写 `latest.release`，否则容易拉到 alpha 并要求更高的 preview compileSdk；统一用 BOM 管理最稳。
