## 修复 lintVitalReportRelease 的 Java 版本错误
- 通过 winget 安装 Microsoft OpenJDK 25（`Microsoft.OpenJDK.25`，25.0.5.21），路径 `C:\Program Files\Microsoft\jdk-25.0.5.21-hotspot`。
- 项目 `app/build.gradle.kts` 的 `sourceCompatibility`/`targetCompatibility` 是 Java 25，但 Gradle 守护进程仍跑在 21。
- `gradle.properties` 增加 `org.gradle.java.home` 与 `org.gradle.java.installations.paths` 指向 JDK 25。
- `settings.gradle.kts` 增加 `org.gradle.toolchains.foojay-resolver-convention` 1.0.0 插件，否则 `updateDaemonJvm` 报"No toolchain download repositories configured"。
- 用 `java -jar gradle/wrapper/gradle-wrapper.jar updateDaemonJvm --jvm-version=25 --jvm-vendor=MICROSOFT --no-configuration-cache --rerun` 重生成 `gradle/gradle-daemon-jvm.properties`（不要只手改 toolchainVersion，否则会联网下载 Adoptium JDK）。
- 验证：`:app:lintVitalReportRelease` BUILD SUCCESSFUL（注意 `--offline` 会因 lint-gradle 依赖未缓存而失败，需联网跑一次）。
