# 2026-09-21

## GitHubUpdateChecker 版本号格式改造 (ScoreMuse)
- 文件: `app/src/main/java/io/github/zeehan2005/scoremuse/components/GitHubUpdateChecker.kt`
- Alpha 版本号改为 `vX.X.X-alpha*`，Beta 改为 `vX.X.X-beta*`（后缀 `*` 任意或为空，大小写不敏感）。
- 渠道判定改为基于 tag 后缀：`alphaRegex`/`betaRegex` 识别 ALPHA/BETA，无后缀时按 GitHub `prerelease` 标记回退（纯 `vX.X.X` 预览版仍视为 BETA，保留历史行为）。
- Alpha/Beta 现在都基于 SemVer 排序（不再用时间戳）；移除了旧 `Alpha-<14位时间戳>` 时间戳解析逻辑（`alphaInstant`/`parseAlpha`/`extractAlphaDigits`/`alphaFormatter`/`parseStableAsApproxInstant` 全部删除）。
- 注意：旧 `Alpha-20240101120000` 时间戳格式已不再被识别为 Alpha。
